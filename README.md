## Overview

**Pink Cream Icons** is a cozy, cute 3D clay and glossy candy icon suite designed for **Elgato Stream Deck**, **evoXdeck**, **Loupedeck**, and **Touch Portal**.

Inspired by cozy gamer girl desk setups, VivreMotion aesthetics, and sweet candy clay art, each tile features pillowy rounded squircles, smooth specular rim highlights, and deep cherry plum contrast accents.

## 🚀 How to Install

### 1. evoX / evoXdeck (1-Click Install)
1. Download **`Pink Cream Icons.evoxpack`** from the [Latest Release](https://github.com/Hfatih/pink-cream-icons/releases/latest).
2. Open **evoXdeck**.
3. Drag and drop the `.evoxpack` file directly into the application window.

### 2. Elgato Stream Deck
1. Extract the **`icons/`** folder from the release archive.
2. In the Elgato Stream Deck software, select any key slot.
3. Drag and drop any 144×144 PNG icon from the `Cream` or `Pink` folder directly onto the key.
