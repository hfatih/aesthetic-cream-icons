## Overview

**Pink Cream Icons** is a cozy 3D clay & jelly aesthetic stream deck icon suite comprising **192 handcrafted icons** across 3 finishes. Inspired by cozy gamer setups, VivreMotion clay aesthetics, and soft pastel desk setups.

### Key Highlights
- **3 Cohesive Finishes (64 unique symbols each):**
  - **Cream (C):** Pillowy warm ivory/cream squircle base with 3D pink clay glyphs.
  - **Pink (P):** Vibrant strawberry bubblegum pink squircle base with 3D pink clay glyphs.
  - **Transparent (T):** Pure transparent background with standalone 3D clay glyphs for custom docks, Touch Portal, and Loupedeck.
- **Retina 144×144 PNG:** Pixel-perfect clarity on Stream Deck MK.2, Plus, XL, Mini, and mobile apps.
- **1-Click evoXdeck Setup:** Packaged in native `.evoxpack` format for instant import.
- **Comprehensive Library:** Streaming (Twitch, YouTube, OBS, Kick), Gaming (Steam, Discord, EA, Epic, Minecraft, Roblox), Social Media, Productivity, and Hardware controls.

## Installation

### 1. evoXdeck (Recommended)
1. Download `Pink Cream Icons.evoxpack` from [Releases](https://github.com/Hfatih/pink-cream-icons/releases/latest).
2. Double click the `.evoxpack` file or click **Install Package** in evoX.
3. Browse and apply icons categorized by finish and application!

### 2. Elgato Stream Deck
1. Download this repo or extract the icons folder.
2. In Elgato Stream Deck app, select any action button.
3. Click the icon thumbnail dropdown and choose **Set from File**.
4. Pick your favorite Cream, Pink, or Transparent icon from the `icons/` directory.
